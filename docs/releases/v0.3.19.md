# v0.3.19 candidate acceptance record

Date: 2026-09-14. Status: **source candidate; not yet published or recommended**.
The accepted registry, GitHub Latest release, GHCR `latest` image and production
deployment remain on v0.3.18 until the immutable v0.3.19 artifacts pass the
remaining gates.

## Problem and scope

The v0.3.18 Plugin Store artifact installs only the dynamic plugin. Its
plugin-pages wrapper still loads the browser-facing `/agent-identity/` sidecar
dashboard. Deployments without that reverse proxy show “Codex Agent Identity
temporarily unavailable” even when CPA can reach the sidecar privately.

This candidate:

- embeds the complete management page, JavaScript, styles and theme bridge in
  `codex-agent-identity.so`;
- adds an authenticated CPA Management API bridge from that page to the private
  sidecar;
- keeps `/agent-identity/` only as an optional compatibility fallback;
- leaves CPA native OAuth ownership, PAT execution, stored identities and the
  sidecar data plane unchanged.

The Plugin Store still cannot create the sidecar container, Docker network,
Management/encryption keys or persistent data directory. A separately deployed
sidecar and private CPA-to-sidecar route remain required.
